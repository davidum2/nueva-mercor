## Original Request
Replace GUIslice's single-bounding-box invalidation model (`bInvalidateEn` + `rInvalidateRect`) with a bounded multi-region dirty-rectangle manager wired through the partial-redraw path:
- Add `GSLC_INVALIDATE_RGN_MAX` (default 8; user config header or compiler define may set 1–32).
- Add three new public functions: `gslc_InvalidateRgnCount` (uint8_t count of active regions, or 0 if invalidation disabled), `gslc_InvalidateRgnGet` (writes active regions canonically sorted ascending by y, then x, then h, then w into caller's array up to a max count when non-null; returns total count), `gslc_InvalidateRgnIsDirty` (bool: positive-area intersection of test rect with ≥1 active region).
- Region set: ≤ `GSLC_INVALIDATE_RGN_MAX` pairwise non-overlapping rects, **no dynamic allocation** anywhere (no malloc family/strdup/asprintf in core or SDL driver code — SDL's internal allocations don't count).
- Add function: clamps each input rect to display bounds, drops empty/fully-offscreen rects; positive-area overlaps transitively coalesce into bounding-box unions until pairwise disjoint (so two non-overlapping invalidations from one element op stay separate regions).
- On count > MAX: repeatedly merge the pair minimizing wasted area (union bbox area − sum of areas); tie-break order-independent: canonically smaller region of each pair first, then lexicographic on (first, second) by y,x,h,w; re-coalesce after each forced merge.
- Screen invalidation = exactly one full-display region; Reset empties set and disables invalidation.
- Redraw: each active region drawn independently with clip rect set to that region before background/element rendering; every element pending redraw must render in each region it intersects (incl. elements spanning multiple regions).
- SDL1 driver's screen presentation must update only individual active regions (exactly one update per region, even if a region covers the whole display; no active regions → whole-display refresh as before); whole-display-only drivers (SDL2) unchanged.
- Region set must remain populated during presentation and be emptied only after redraw+presentation completes, at which point clipping is restored to full display.

## Early Progress
Extensive code exploration completed; no code changes yet. Key findings:
- **Current model**: `gslc_tsGui` has `bool bInvalidateEn` + `gslc_tsRect rInvalidateRect` (GUIslice.h ~848-849), used only in GUIslice.c/GUIslice.h (nothing in examples/docs/builder references them).
- **Current functions** (GUIslice.c ~1456-1497): `gslc_InvalidateRgnReset/Screen/Page/Add` built on `gslc_UnionRect`. `gslc_InvalidateRgnPage` calls Add then a redundant `bInvalidateEn = true`.
- **Redraw flow**: `gslc_PageRedrawGo` (~2314): `gslc_PageRedrawCalc` → `bPageRedraw = gslc_PageRedrawGet` → set clip to `rInvalidateRect` (or NULL) → if full redraw: `gslc_DrvDrawBkgnd` + `gslc_PageFlipSet(true)` → dispatch GSLC_EVT_DRAW (subtype FORCE if full else NEEDED) to all stack pages (`gslc_PageEvent` → `gslc_CollectEvent` → `gslc_ElemEvent` → `gslc_ElemDrawByRef`) → `gslc_PageRedrawSet(false)` → `gslc_InvalidateRgnReset` → `gslc_SetClipRect(NULL)` → `bRedrawNeeded=false` → `gslc_PageFlipGo`. **Reset currently happens BEFORE flip — must be reordered** so regions survive presentation.
- **Key challenge & chosen solution**: `gslc_ElemDrawByRef` clears the element's redraw flag via `gslc_ElemSetRedraw(...,GSLC_REDRAW_NONE)` (~line 3251; also 3106 invisible, 3152 focus), so a naive per-region loop loses pending redraws after region 1. **Decision**: add an internal "hold" flag in `gslc_tsGui`; in `gslc_ElemSetRedraw`'s `GSLC_REDRAW_NONE` branch, early-return (skip clearing and parent propagation) while hold is active; hold is set for every region pass except the last, so clearing happens naturally on the final pass. (Rejected: spare eElemFlags bits 8/9 as snapshot — `gslc_SetElemRefFlag` truncates flags to `uint8_t` at line ~2550.)
- `gslc_ElemSetRedraw` (~3511) also calls `gslc_InvalidateRgnAdd(pGui,pElem->rElem)` on redraw requests and sets `bRedrawNeeded=true`; NONE-branch clears redraw bits and propagates NONE to `pElemRefParent`.
- **Struct/type facts**: `gslc_tsRect` = `{int16_t x,y; uint16_t w,h}`; edges assumed to fit signed 16-bit (use uint32_t area math). `gslc_teElemRefFlags`: SRC=bits1-0, EDITING=1<<2, FOCUSED=1<<3, REDRAW_*=bits5-4 (mask 3<<4), GLOWING=1<<6, VISIBLE=1<<7. ElemRef structs are RAM-resident even for PROG/CONST elements.
- **Other callers**: `gslc_SetStackPage` (~2085) invalidates old + new stack pages and sets `gslc_PageRedrawSet(true)` on change; `gslc_ElemSetRect` (~3364) adds old+new rects (naturally stay separate when non-overlapping); `gslc_ElemSetVisible` adds hidden element's rect; `gslc_Quit`/`gslc_SetBkgnd*`/rotate use InvalidateRgnScreen; `gslc_Init` calls `gslc_InvalidateRgnScreen`.
- **SDL1 driver** (`GUIslice_drv_sdl.c`): `gslc_DrvPageFlipNow` (~656) does `SDL_Flip(pScreen)` for SDL1; SDL2 does RenderPresent+clear (leave unchanged). Screen surface: `SDL_SetVideoMode(..., SDL_SWSURFACE|SDL_FULLSCREEN)` — software surface, so per-region `SDL_UpdateRect` is the correct partial-update call. `gslc_DrvSetClipRect` (~505) uses `SDL_SetClipRect` (SDL1) / `SDL_RenderSetClipRect` (SDL2) with `gslc_DrvAdaptRect`. `gslc_DrvDrawBkgnd` (~828) blits background surface (honors clip rect). Drivers set `bRedrawPartialEn`: SDL1=true (~100), SDL2=false (~108), adagfx/tft_espi/utft/m5stack true.
- `gslc_PageFlipGo` (~2445): only calls `gslc_DrvPageFlipNow` when `pGui->bScreenNeedFlip`, then `gslc_PageFlipSet(false)`. `gslc_PageFlipSet` with DBG_DRAW_IMM can call DrvPageFlipNow at draw time (regions active — fine).
- **Config mechanism**: GUIslice.h includes GUIslice_config.h → stock `configs/*.h` (e.g. `linux-sdl1-default-mouse.h`); override-defaults pattern (`#ifndef ... #define`) exists in GUIslice.h (e.g. GSLC_FEATURE_FOCUS_ON_TOUCH ~line 68). Plan: put `#ifndef GSLC_INVALIDATE_RGN_MAX / #define 8 / #endif` + range-check `#error` in GUIslice.h after the config include; `nDispW`/`nDispH` are `uint16_t`.
- **Planned implementation details**: maintain `asInvalidateRgn[GSLC_INVALIDATE_RGN_MAX]` + `uint8_t nInvalidateRgnCnt` in gslc_tsGui (replacing `rInvalidateRect`), invariant `bInvalidateEn == (count>0)`; canonical compare (y,x,h,w); transitive coalesce loop until fixpoint; forced-merge pair selection with canonical ordering + lexicographic tie-break then re-coalesce; Get copies canonically sorted regions (sort into local buffer in Get; internal order need not be maintained sorted, drawing order of disjoint regions doesn't matter); redraw loop uses local `gslc_tsRect asRgn[GSLC_INVALIDATE_RGN_MAX]` snapshot via `gslc_InvalidateRgnGet`; DBG_REDRAW prints/delay(1000)/`gslc_DrvDrawFrameRect` marker in PageRedrawGo reference `rInvalidateRect` and need updating.
